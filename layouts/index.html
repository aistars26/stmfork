Search the Ultimate Stabat Mater Website

This proof of concept shows how the Stabat Mater website could run as a static Hugo site on GitHub Pages. It includes representative content types for composers, texts, translations, blog posts and informational pages.

The goal is not a full migration yet, but a functional demonstration that the structure, navigation and visual style can work without depending on the production WordPress site.

Explore the content types

Composers

Alphabetical list with composer detail pages and recording metadata.

Texts

Static explanatory pages about the poem and its liturgical or literary context.

Translations

Translation landing pages plus individual language pages.

Blog

News and editorial posts in a classic archive + single-post layout.

Why this POC exists

The original Stabat Mater website has a rich visual identity and many page types. This Hugo fork is meant to show that the same basic experience can be reproduced on GitHub Pages with static content, reusable layouts and a simpler deployment flow.
